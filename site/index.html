PortSentinel

Finds externally exposed ports on your Linux servers, checks them against a default-deny policy, and closes the gap with safe, reversible nftables rules.

Download GitHub

No Nmap required

Concurrent TCP probes, IPv4/IPv6, banner grabbing and process mapping via /proc.

Default-deny policy

Allowlists, ranges, expiring exceptions. SSH and management ports are always protected.

Safe enforcement

Own nftables table only, validated with nft -c, atomic apply, timed auto-revert and rollback.

Auditable

Every scan, apply and rollback is written to a JSON Lines audit log.

Quick start

curl -LO https://github.com/bakhod1r/portsentinel/releases/latest/download/portsentinel_v0.1.0_linux_amd64.tar.gz
tar xzf portsentinel_v0.1.0_linux_amd64.tar.gz && cd portsentinel_v0.1.0_linux_amd64
sudo ./portsentinel init
sudo ./portsentinel audit
sudo ./portsentinel tui

Plan before you apply

v0.1.0 is a preview: use audit, plan and tui. Same-host verification in apply is a known issue.
